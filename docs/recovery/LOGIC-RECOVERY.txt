READABLE SCRIPT LISTINGS
VM-SCRIPTS contains430 address-named .txt files. INDEX.txt lists named entry points. Each line gives ROM location,token word,operation,operand and branch/call destination; inline alpha/lamp command streams are decoded. A leading* means the dispatch site was observed in MAME. Other reachable branches are static deductions; this marker does not claim every possible operand/state was tested. Literal and branch payload bytes are separated from tokens, including odd-aligned word addresses.

The VM uses Y as cursor,U as data stack,and S for returns/loop/local frames. F8 enters a nested definition;FC dispatches a word through its code-pointer header. This pass also recovered shared-body entries whose three-byte native JSR796E is followed by tokens. The trampoline pushes the calling word's body address and swaps the native return PC with the outer VM cursor. Only that prefix is6809 code. Native inline display/input/lamp calls had64 continuation boundaries refined, so Ghidra skips their embedded arguments. The extra lamp pattern-F stub at497F was corrected as a tail-return stub.

Decoder validation across the recorded baseline/discovery/corrected play traces:
 1,821 distinct observed dispatch locations, with zero token-word mismatches.
 607,883 checked ordinary next-token transitions, with zero mismatches.
 Native calls,returns,dynamic execution and loop/local-frame transfers require separate context and are excluded from the ordinary continuation count. Handler mechanics are derived from saved6809 assembly; this is not validation of every game outcome or full symbolic stack interpretation.
 Four static sites remain unresolved:ADBA,AC46,AC5F,9AD0. Their payloads/tokens are left unresolved; none appeared in the recorded execution. No claim of complete ROM coverage is made.

GAME LOGIC RECOVERED FROM THESE PATHS
AB64 conditionally decrements the credit shadow when E0 is set and shadow equals credits, then decrements02F0 and refreshes NVRAM complement/checksum state. It records stake accounting through AB33; the observed normal path increments03FE twice per consumed credit. A7AB prints02F0 through alpha command76,and its fractional branch appends .5. FC34 calls F384; the latter reaches F2B5,which resets sound/scheduler,prepares lamps,starts native reel motion,waits and refreshes symbol records.
FBA2 gates entry to the attract path using no-credit/bank/mode conditions and a timer. FA7F enters the lamp/display attract sequence. The no-input trace validates the observed branch and repeating outputs; alternative DIP/service/bank branches remain static deductions.

LIMITS AND EVIDENCE
Names are recovered descriptions,not original identifiers. There are still51 neutral native function names and24 explicit hypotheses. Script decoding is a reachable token/control-flow listing,not structured original-source recovery. Standard6809 decompilation still has limitations at indirect/native-inline/custom-stack boundaries; saved assembly and VM listings are the reference where pseudocode warns or disagrees. No ROM bug or emulator defect is claimed by these experiments. Payout correctness and unvisited feature outcomes remain unverified.
