HOW TO USE THE INDEX
VM-SCRIPTS/INDEX.txt lists each script's purpose or unresolved status,confidence,groups,observed-site fraction,up to eight main callers,and callees. The complete caller sets are in evidence/script-pass/script-classification.json. Parameterized word instances are listed separately at the end of INDEX.txt. Each individual script listing now carries its purpose,confidence,groups and callers above its decoded tokens.
Exact helper-pattern names describe narrow mechanics. Reviewed token names derive from assembled handler semantics and decoded control flow. Reviewed gameplay-context names additionally use callers,display text and/or repeated state-transition evidence. Grouping-only descriptions are not asserted game-role names.
The analyzer follows direct script calls and observed EXECUTE targets. EXECUTE bypasses FC for the dispatch itself; its target is recovered from the recorded top stack cell. This identified additional button-condition headers,including83B4 and83B7. Unobserved computed table entries remain a limitation of the caller graph.
